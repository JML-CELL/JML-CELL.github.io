The journal study develops distributed subchannel allocation around identifiers embedded in data traffic. Jamming and cancellation carry the identifiers while preserving the useful data transmission. Stations use the observations to learn a channel-access strategy, reducing the need for repeated standalone coordination exchanges.

The resulting schedule approaches TDMA-like operation: stations learn both the appropriate transmission time and subchannel. Simulations compare AT-Learning with multichannel random access such as Slotted ALOHA. The study explains how low-cost physical-layer signaling can support efficient distributed scheduling.
