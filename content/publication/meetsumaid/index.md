Automatically generated meeting notes can omit context or contain errors that are difficult to catch in a mobile workflow. MeetSumAid treats summary creation as an interactive process: users inspect emerging notes, edit their content, and supply feedback instead of accepting a finished summary without review. The interface connects these controls to the underlying summarization system.

A study with 20 participants evaluates summary quality, generation efficiency, perceived reliability, and cognitive load against baseline AI summarizers. The paper reports improvements across these dimensions and analyzes how individual interface components support engagement. Its contribution is a mobile workflow for reviewing and refining AI output while preserving user control.
