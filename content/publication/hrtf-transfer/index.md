Measuring a full individualized head-related transfer function is time-consuming. Parameter-transfer learning first trains a general neural model on an existing HRTF database, using acoustic-domain knowledge to define features and the loss. A small set of measurements from the target listener then adapts selected model parameters.

Objective spectral-distance tests and subjective localization experiments evaluate the personalized result. The contribution is a way to transfer a model across listeners while using limited individual calibration data, connecting physical acoustic knowledge with learned spatial-audio personalization.
