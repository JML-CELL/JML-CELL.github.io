G-Fall decomposes a falling event into time-dependent floor-vibration features measured by geophones. A Hidden Markov Model captures their sequence, using a previously learned template instead of requiring each monitored user to perform training falls. An Energy-of-Arrival positioning mechanism provides an additional check on detected events.

Experiments with 12 participants assess recognition and false alarms, reporting 95.74% recognition precision before the additional positioning confirmation. The work investigates how physical event modeling and spatial evidence can make device-free fall detection more selective.
