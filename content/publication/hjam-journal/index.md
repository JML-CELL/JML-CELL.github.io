Wireless coordination normally competes with data packets for airtime. hJam changes that relationship by allowing control messages to accompany a data transmission. The design exploits OFDM’s physical-layer structure so that one data packet and several control messages can share the same transmission interval.

The authors implement the mechanism on an eight-node USRP2/GNU Radio testbed and evaluate network behavior through simulation. The work provides a communication model for reducing coordination overhead while retaining explicit control exchange in a multi-station WLAN.
