Pest activity can be difficult to observe when leaves occlude an insect or illumination changes. This work uses the plant’s electrophysiological response as a complementary source of information. HIPB-MM provides 4,023 synchronized signal–video recordings covering the feeding behavior of three pest species, supporting a direct comparison between physiological and visual evidence.

The HIPS framework separates slow-wave signal semantics from morphology, models latent physiological states, and uses a dual-stream visual branch to improve signal representations. It achieves 69.81% classification accuracy in the reported benchmark. The study contributes both a multimodal dataset and a specialized modeling approach for weak, non-stationary plant signals.
